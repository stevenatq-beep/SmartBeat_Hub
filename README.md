# SmartBeat_Hub
SmartBeat Hub es una bocina inteligente desarrollada como proyecto de electrónica y programación. Utiliza Spotify Connect, integra audio, hardware y LEDs, y aplica trabajo colaborativo usando Git y GitHub para documentar y organizar el desarrollo del sistema.

**COMO FUNCIONARÁ?**

Será un ESP32, que usando un Spotify Connect, se conecte en la Web y despues de eso, se conecte directamente a la bocina, mediante un modulo BT qué pasará a el amplificador, para poder dar buena música.
